About me

I’m Leela Prasad Etuka, a Machine Learning Developer from Sri Kalahasti, Andhra Pradesh. I turn raw, messy data into production-style analytics and machine learning applications, from data cleaning and feature engineering to model building and interactive Streamlit dashboards.

Across 5 end-to-end projects I have analysed 370,000+ records, defined 25+ KPIs and shipped 5 interactive apps: segmenting 3,000 learners into 4 behavioural personas, decoding profitability across 1,696 restaurant branches, mining 12.97 million ferry tickets for demand patterns, and stress-testing 100,000 smart-factory telemetry records against 6G network performance.

My toolkit is Python, Pandas, NumPy, Scikit-learn and Plotly for data and modelling, with Streamlit, FastAPI, MLflow, Docker and Git for building, tracking and shipping. At Unified Mentor I worked as a Machine Learning Developer, delivering projects from raw dataset to deployed dashboard. I’m open to Machine Learning Developer and Engineer opportunities.
